# نیازمندی‌های سیستم دستگاه فروش خودکار هوشمند

## ۱. نیازمندی‌های عملکردی

نیازمندی‌های عملکردی مشخص می‌کنند که سیستم باید چه وظایفی را انجام دهد.

| شناسه | شرح نیازمندی |
|---|---|
| FR-01 | سیستم باید کالاهای موجود و قیمت آن‌ها را نمایش دهد. |
| FR-02 | سیستم باید امکان انتخاب کالا را برای مشتری فراهم کند. |
| FR-03 | سیستم باید پرداخت با سکه را بپذیرد. |
| FR-04 | سیستم باید امکان ارسال درخواست پرداخت کارتی به سرویس پرداخت خارجی را فراهم کند. |
| FR-05 | سیستم باید پیش از تحویل کالا، نتیجه پرداخت را بررسی کند. |
| FR-06 | سیستم باید پیش از تکمیل خرید، موجود بودن کالای انتخاب‌شده را بررسی کند. |
| FR-07 | سیستم باید پس از تأیید پرداخت و موجودی، فرایند تحویل کالا را آغاز کند. |
| FR-08 | سیستم باید باقی‌مانده وجه را در پرداخت‌های سکه‌ای محاسبه و بازگرداند. |
| FR-09 | سیستم باید در صورت ناموفق بودن خرید پس از پرداخت، فرایند بازپرداخت وجه را آغاز کند. |
| FR-10 | سیستم باید پس از تحویل موفق کالا، موجودی آن را به‌روزرسانی کند. |
| FR-11 | سیستم باید به اپراتور مجاز اجازه دهد تعداد کالاهای موجود را تغییر دهد. |
| FR-12 | سیستم باید هنگام بروز خطا، پیام مناسبی به مشتری نمایش دهد. |

## ۲. نیازمندی‌های غیرعملکردی

نیازمندی‌های غیرعملکردی ویژگی‌های کیفی و محدودیت‌های عملکرد سیستم را مشخص می‌کنند.

| شناسه | ویژگی | شرح نیازمندی |
|---|---|---|
| NFR-01 | سهولت استفاده | مراحل انتخاب کالا و پرداخت باید ساده و قابل فهم باشند. |
| NFR-02 | کارایی | سیستم باید در شرایط عادی، نتیجه انتخاب کالا را حداکثر ظرف ۲ ثانیه نمایش دهد. |
| NFR-03 | امنیت | دسترسی به امکانات مدیریتی باید به کاربران مجاز محدود شود. |
| NFR-04 | قابلیت اطمینان | کالا نباید پیش از تأیید پرداخت و بررسی موجودی تحویل داده شود. |
| NFR-05 | صحت داده‌ها | موجودی باید مطابق نتیجه واقعی تحویل کالا به‌روزرسانی شود. |
| NFR-06 | قابلیت نگهداری | ساختار سیستم و اجزای آن باید مستند و قابل بررسی باشند. |
| NFR-07 | مدیریت خطا | سیستم باید خطاهای پرداخت، موجودی و تحویل کالا را شناسایی کند و پیام مناسبی نمایش دهد. |

## ۳. محدودیت‌ها و فرضیات

- پرداخت کارتی به سرویس پرداخت خارجی وابسته است.
- تحویل کالا به عملکرد صحیح سازوکار فیزیکی دستگاه وابسته است.
- سیستم باید پرداخت ناموفق و ناموجود بودن کالا را مدیریت کند.
- زمان پاسخ ۲ ثانیه یک هدف پیشنهادی برای پروژه است و باید در آزمون‌ها بررسی شود.
