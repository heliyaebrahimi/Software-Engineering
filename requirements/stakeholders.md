# شناسایی ذی‌نفعان پروژه

## ۱. معرفی

ذی‌نفعان افراد یا گروه‌هایی هستند که از سیستم استفاده می‌کنند، بر آن تأثیر می‌گذارند یا از عملکرد آن تأثیر می‌پذیرند.

در پروژه دستگاه فروش خودکار هوشمند، ذی‌نفعان اصلی شامل مشتری، اپراتور دستگاه، مدیر سیستم، ارائه‌دهنده خدمات پرداخت، تعمیرکار و مالک دستگاه هستند.

## ۲. فهرست ذی‌نفعان

| ذی‌نفع | نقش | نیاز اصلی |
|---|---|---|
| مشتری | استفاده‌کننده اصلی سیستم | خرید آسان و دریافت صحیح کالا |
| اپراتور دستگاه | مدیریت موجودی | مشاهده و به‌روزرسانی موجودی کالاها |
| مدیر سیستم | مدیریت تنظیمات | مدیریت قیمت‌ها و تنظیمات سیستم |
| ارائه‌دهنده خدمات پرداخت | پردازش پرداخت‌های کارتی | دریافت درخواست معتبر و پردازش صحیح پرداخت |
| تعمیرکار | نگهداری دستگاه | شناسایی و رفع خطاهای فنی |
| مالک دستگاه | بهره‌بردار تجاری | افزایش قابلیت اطمینان و رضایت مشتری |

## ۳. نیازهای ذی‌نفعان

- مشتری باید بتواند کالاها و قیمت‌ها را مشاهده و خرید خود را انجام دهد.
- اپراتور باید بتواند موجودی کالاها را بررسی و اصلاح کند.
- مدیر سیستم باید امکان مدیریت قیمت‌ها و تنظیمات را داشته باشد.
- ارائه‌دهنده خدمات پرداخت باید نتیجه تراکنش را به‌درستی مشخص کند.
- تعمیرکار باید بتواند خطاهای فنی دستگاه را شناسایی کند.
- مالک دستگاه باید از عملکرد صحیح و کاهش خطاهای فروش اطمینان داشته باشد.

## ۴. فرضیات اولیه

- دستگاه از پرداخت با سکه و کارت بانکی پشتیبانی می‌کند.
- پیش از تکمیل خرید، موجودی کالا بررسی می‌شود.
- پس از تحویل موفق کالا، موجودی آن به‌روزرسانی می‌شود.
- پردازش پرداخت کارتی توسط یک سرویس خارجی انجام می‌شود.
- دسترسی به امکانات مدیریتی فقط برای افراد مجاز امکان‌پذیر است.
