# 🥤smart vending machine

## ۱. معرفی پروژه

این پروژه با هدف تحلیل و مدل‌سازی یک دستگاه فروش خودکار هوشمند انجام می‌شود. این دستگاه به مشتریان اجازه می‌دهد کالاهای موجود را مشاهده کنند، کالای موردنظر خود را انتخاب کنند، هزینه را از طریق سکه یا کارت بانکی پرداخت کنند و کالای خریداری‌شده را تحویل بگیرند.

سیستم همچنین مسئول بررسی موجودی کالاها، محاسبه و بازگرداندن باقی‌مانده وجه، مدیریت خطاهای پرداخت و به‌روزرسانی موجودی پس از تحویل موفق کالا است.

## ۲. اهداف پروژه

- شناسایی ذی‌نفعان و نیازهای آن‌ها
- استخراج نیازمندی‌های عملکردی و غیرعملکردی
- نگارش داستان‌های کاربر و تشکیل فهرست کارهای محصول
- اولویت‌بندی نیازمندی‌ها بر اساس روش چابک
- مدل‌سازی رفتار سیستم با استفاده از نمودارهای UML
- تقسیم سیستم به ماژول‌های مستقل
- بررسی انسجام و وابستگی ماژول‌ها
- مستندسازی و مدیریت تغییرات پروژه در GitHub

## ۳. محدوده پروژه

قابلیت‌های اصلی سیستم عبارت‌اند از:

- نمایش کالاها و قیمت‌های آن‌ها
- انتخاب کالای موردنظر
- دریافت و اعتبارسنجی پرداخت
- پشتیبانی از پرداخت نقدی و کارتی
- تحویل کالا پس از پرداخت موفق
- بازگرداندن باقی‌مانده وجه یا آغاز فرایند بازپرداخت
- مدیریت موجودی کالاها
- نمایش پیام‌های مناسب در صورت بروز خطا

## ۴. روش توسعه

در این پروژه از روش توسعه چابک (Agile) استفاده می‌شود. فعالیت‌ها به بخش‌های کوچک تقسیم می‌شوند و مستندات در چند مرحله تهیه، بررسی و اصلاح خواهند شد.

## ۵. ابزارهای مورد استفاده

- GitHub برای نگهداری مخزن و ثبت تغییرات
- Markdown برای نگارش مستندات
- Mermaid برای رسم نمودارهای فرایندی
- PlantUML برای رسم نمودارهای UML
